1. HEDERA ($15,000 Prize Category)
--------------------------------------------------------------------------------
Why Foundereum is applicable:
Foundereum uses Hedera as the foundational micro-settlement, audit, and smart 
contract execution layer for autonomous AI agents. Every agent tool invocation 
is gated by HTTP 402 (x402) micropayments denominated in HTS USDC settled on 
Hedera Testnet. The Blocky402 facilitator pays network transaction fees, while 
Hedera Consensus Service (HCS) immutably logs every settled tool call, payment 
receipt, and policy evaluation to a public audit topic. Agents also interact with 
Hedera EVM (Chain ID 296) for DEX token swaps and decentralized agent identity.

Partner Ease-of-Use Rating: 9/10
Feedback: HCS consensus finality and HTS token transfer performance are 
outstanding for sub-second agentic tool execution. The hiero-sdk-go / hedera-sdk-go 
made token transfer construction and topic submission seamless.

2. THE GRAPH ($15,000 Prize Category)
--------------------------------------------------------------------------------
Why Foundereum is applicable:
Foundereum equips AI agents with Model Context Protocol (MCP) tools that query 
The Graph's decentralized network. Through standardized Messari DEX subgraphs, 
agents can query real-time pool metrics, liquidity depth, daily volume, and 
compare protocol TVL across chains. Tool calls are dynamically metered and paid 
per query KB. To prevent prompt injection and indirect jailbreaks, all raw 
subgraph payloads returned to LLMs are sanitized and strictly enveloped with 
`data (untrusted):` guardrails.

Partner Ease-of-Use Rating: 9/10
Feedback: Standardized schemas (Messari) provide consistent GraphQL interfaces 
for agent tool calling across multiple protocols. Subgraph indexing speed and 
GraphQL query latency were smooth and highly reliable.

3. PRIVY ($5,000 Prize Category)
--------------------------------------------------------------------------------
Why Foundereum is applicable:
Foundereum leverages Privy Server Wallets within secure Trusted Execution 
Environments (TEEs) to manage private keys for both project treasuries and 
autonomous agents. Agents sign micro-settlement transfers and EVM contract calls 
without ever having direct access to raw private keys. Foundereum integrates 
Privy with WebCrypto P-256 multi-party quorum signatures, enforcing strict 
m-of-n human approvals for withdrawals exceeding policy thresholds.

Partner Ease-of-Use Rating: 9/10
Feedback: Privy Server Wallets API made non-custodial agent authorization simple 
and cryptographically sound. TEE-backed signing provides defense-in-depth against 
compromised agent runtimes.
